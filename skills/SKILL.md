# Title

Tweet Generator Skill

## Description

Generates engaging Twitter posts based on a topic.

## Instructions

1. Take user input topic
2. Generate 3 tweet variations
3. Keep under 280 characters
4. Add relevant hashtags

## Context

* Input: user prompt
* Output: tweet text

## Examples

### Input:

AI in healthcare

### Output:

1. AI is transforming healthcare faster than ever 🚀 #AI #HealthTech  
2. Smarter diagnoses, better outcomes 🤖 #FutureOfHealthcare  
3. The future of medicine is intelligent and data-driven 💡 #MedTech #AI
